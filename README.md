 
# Line Dancing John

A responsive full-stack website built with Flask for Line Dancing John.

## Features

- Responsive mobile-first design
- Upcoming events
- Weekly recurring events
- Special event management
- Cruise event support
- Photo gallery
- Contact page
- Facebook & Instagram integration
- Secure admin dashboard
- Image uploads
- SQLite database

## Technologies

- Python
- Flask
- Bootstrap 5
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript

## Project Goals

Create a modern website that allows John to manage his events, photos, and social media without needing technical knowledge.
